# Tabata

Intervalový časovač (Tabata, HIIT, EMOM) ako webová appka pre iPhone.

**Inštalácia na iPhone:** otvor odkaz v Safari → Zdieľať → *Pridať na plochu* → spúšťaj z ikony.
Po prvom otvorení funguje aj offline.

Zvuky sú zapečené do jednej zvukovej stopy, takže pípajú aj so zamknutou obrazovkou. Počas tréningu sa pozastaví hudba z iných appiek.
Vibrácie iPhone cez web nepodporuje.

Technické detaily: pozri `CLAUDE.md`.
